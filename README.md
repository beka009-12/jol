# Jol

Туристическая система Кыргызстана: турфирмы, жильё, еда и места в одном каталоге, AI-гид, определение места по фото и данные безопасности поездки.

Next.js (App Router), TypeScript strict, Tailwind v4 + shadcn/ui, next-intl (en/ru), TanStack Query.

## Запуск

```bash
cp .env.example .env
npm install
npm run dev
```

| Команда | Что делает |
|---|---|
| `npm run dev` | Dev-сервер |
| `npm run build` | Продакшен-сборка |
| `npm run lint` | ESLint |
| `npm test` | Unit-тесты: цены и даты, разбор стрима, ссылки в ответах AI |

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `BACKEND_URL` | Адрес FastAPI. Читается при сборке: на него указывает rewrite `/backend/*` |
| `NEXT_PUBLIC_USE_MOCKS` | `true`: каталог (места, туры, жильё, еда, компании, поиск, заявки) берётся из `lib/mocks` |
| `NEXT_PUBLIC_GOOGLE_CLIENT_ID` | OAuth Client ID. Должен совпадать с тем, что проверяет бэкенд |
| `NEXT_PUBLIC_KGS_PER_USD` | Курс для подсказки `~$` в ценах |
| `NEXT_PUBLIC_SITE_URL` | Адрес сайта для Open Graph. На Vercel определяется сам |

На Vercel задайте их в настройках проекта: `NEXT_PUBLIC_*` и `BACKEND_URL` используются при сборке.

## Как устроены данные

- Клиентский код ходит только на `/backend/...`, серверные компоненты на `BACKEND_URL` напрямую с `revalidate: 60`.
- Весь доступ к API только через `lib/api/server.ts` и `lib/api/client.ts`.
- **`lib/types.ts` содержит контракт каталога.** Эндпоинты `/places`, `/tours`, `/seasons`, `/quote`, `/requests` пока не готовы: типы описывают ожидаемую форму ответов, моки возвращают ровно её. Когда эндпоинт появится, поставьте `NEXT_PUBLIC_USE_MOCKS=false`.
- Если задан режим моков и нет Google Client ID, вход заменяется демо-аккаунтом, а чат отвечает примерами из `lib/mocks/guide.ts`.

## Договорённости с бэкендом

- **Стрим:** `lib/api/stream.ts` принимает обычный текст, SSE (`data: {"delta": "..."}`) и NDJSON.
- **Карточки в ответе AI:** чтобы показать карточку, AI пишет `[[tour:slug]]` или `[[place:slug]]`, либо ссылку `/tours/slug`, `/places/slug`.
- **Ошибки:** читаются и `{"error": {"code", "message"}}`, и стандартный FastAPI `{"detail": ...}`.

## Как устроена система

Пять разделов каталога: туры, жильё, еда, компании и места. Один поиск по всем (`/search`) и схема дорог на главной (`lib/road-scheme.ts`). Страница места и карточка тура показывают, что ещё есть рядом. Компании подают заявку через `/business`.

Эндпоинтов для новых разделов на бэкенде пока нет, поэтому они работают на демо-данных из `lib/mocks/businesses.ts`: названия, цены, рейтинги и контакты вымышлены. Ожидаемая форма ответов описана в `lib/types.ts`:

| Метод | Путь |
|---|---|
| GET | `/hotels`, `/hotels/{slug}` |
| GET | `/restaurants`, `/restaurants/{slug}` |
| GET | `/companies`, `/companies/{slug}` |
| GET | `/search?q=&region=&month=` |
| POST | `/business-applications` |

Ещё фронтенд ждёт от `/tours` фильтры `region` и `operator`, а от тура `operator.slug`. График «Сколько людей по месяцам» строится из необязательного поля `crowd_by_month` у тура, места, жилья и заведения: 12 чисел с января в любом масштабе. Сейчас эти числа придуманы (`lib/mocks/catalog.ts`). Пока поля нет, график просто не показывается. Главная читает весь каталог с `limit=100`. С `NEXT_PUBLIC_USE_MOCKS=false` разделы без эндпоинта покажут ошибку загрузки.

## Дизайн-система

Токены лежат в `app/globals.css`. Шкала интерфейса `text-xs`…`text-2xl` переопределена как 13 / 15 / 16 / 20 / 24 / 32, поэтому текст мельче 13 px написать случайно нельзя. Заголовки набраны `font-display` (Sofia Sans Extra Condensed) размерами `text-display-sm`…`text-display-xl`, остальной текст Onest. Скругления: `rounded-xl` 12 (кнопки и фильтры), `rounded-2xl` 16 (карточки и фото), `rounded-full` только для бейджей статуса.

Красный `primary` с флага это логотип, главное действие и текущий раздел. Тёмные блоки сделаны цветом `deep`, рейтинги и выбранное на тёмном фоне цветом `sun`.
